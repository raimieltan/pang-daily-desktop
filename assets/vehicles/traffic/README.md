# Roadside traffic

Built by `tools/vehicle_builders/build-roadside-traffic.py` from the reference meshes in
`reference-assets/` (fitted to scale, recoloured to flat named materials, decimated, wheels split
into `wheel_*` nodes, riders posed on the seat with hands on the grips and feet on the pegs).
