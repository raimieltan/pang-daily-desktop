# Archive (Babylon era)

Docs carried over from the retired Babylon/Next.js build on 2026-10-15 and archived on 2026-10-16.
They are reference only: the canon design is `docs/GAME_DESIGN.md`, and it wins wherever these disagree.

Still useful as raw material:

- `ECONOMY_GARAGE.md`, `M2_ECONOMY_BALANCE.md`, `CONDITION_REPAIR.md` — old economy and repair numbers
- `HUB_LAYOUT.md` — old hub layout
- `HANDLING_TUNING.md` — old arcade handling notes (the Godot build uses the simulated model instead)
- `VEHICLE_ASSETS.md` — GLB conventions the car models were built to
- `superpowers/` — Babylon-era plans and the suspension design spec the Godot sim was ported from

Superseded: `GAME_VISION.md`, `STORY_CANON.md` and the chapters, police, social, auth, backend, persistence
and browser-save docs, and `ART_DIRECTION_babylon.md` (replaced by `docs/ART_DIRECTION.md`).
